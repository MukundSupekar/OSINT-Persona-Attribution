# OSINT Online Persona Attribution

A cybersecurity OSINT project focused on investigating a fictitious online persona using publicly available information. The project demonstrates how multiple OSINT techniques can be combined to discover, correlate, and validate digital identities while maintaining an evidence-based investigation process.

## Project Overview

The investigation starts with a fictitious target alias and sample posts. Various OSINT tools and techniques are used to identify potential accounts, analyze relationships, correlate information across platforms, and construct an evidence chain.

## Tools Used

* IntelTechniques
* Sherlock
* WhatsMyName
* theHarvester
* dig
* nslookup
* whoami
* WHOIS
* SpiderFoot
* OSINT Framework
* ExifTool
* Maltego
* Gephi

## Techniques Demonstrated

* Username enumeration
* Cross-platform account correlation
* Social graph analysis
* Domain and DNS reconnaissance
* Image metadata analysis
* Automated OSINT collection
* Relationship mapping
* Timeline analysis
* Evidence collection and validation
* False-positive analysis

## Evidence & Documentation

The project maintains investigation logs, screenshots, tool outputs, evidence IDs, and an evidence matrix to make the investigation reproducible and demonstrate how individual findings contribute to the final attribution assessment.

## Ethical Scope

This project uses a controlled/fictitious target for educational purposes. It focuses only on publicly available or authorized information and does not involve unauthorized access, credential attacks, privacy bypasses, or collection of private information.

## Learning Outcome

This project provides practical experience in OSINT methodology, digital footprint analysis, cross-platform correlation, graph-based investigation, evidence handling, and professional cybersecurity reporting.
